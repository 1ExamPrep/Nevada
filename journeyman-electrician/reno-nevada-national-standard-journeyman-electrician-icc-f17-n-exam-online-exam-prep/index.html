The Reno Nevada National Standard Journeyman Electrician (ICC - F17-N) exam is an open book test. Open book testing allows candidates to use approved references during the exam, but it still requires serious preparation. Candidates must be able to identify the topic, choose the correct reference, locate the controlling section, and apply the rule accurately within the time limit.

NFPA 70: National Electrical Code Handbook, 2014 Edition should be used as the main code reference during preparation. A journeyman-level question may require quick movement between Article 100 definitions, wiring and protection rules, wiring method articles, grounding and bonding provisions, equipment articles, motor rules, special occupancy requirements, and calculation sections.

Ugly’s Electrical References should be used to support calculation review and practical electrical reference study. Candidates can use it to reinforce formulas, symbols, conversions, conductor information, Ohm’s law, power formulas, voltage drop awareness, and other common trade reference topics. Open book success depends heavily on reference navigation. Candidates should practice looking up topics repeatedly until the process becomes familiar. A question about a motor branch circuit should lead toward motor rules and the correct table or calculation method. A question about box fill should lead toward the applicable box fill requirements and conductor volume allowances. A question about grounding should lead toward the correct grounding or bonding rule instead of a general memory-based answer.

Timed practice is essential. Candidates should answer mixed-topic questions with the references open and a clock running. This helps build pacing and shows which topics take too long to locate. Over time, repeated lookup practice helps reduce hesitation and improves confidence during preparation.

How does the Journeyman Electrician (ICC G17) exam work?

The Journeyman Electrician (ICC G17) card is part of the Electrical Qualifications ID card program run by Electrical Safety Professionals for Las Vegas, Clark County and Reno. You pass the ICC national exam, then apply to ESP with the score report.

  • The ICC G17 Journeyman Electrician exam has 80 questions in 4 hours and is open book with the NEC.
  • The ID card is valid for 3 years and renews with continuing education from an approved provider.
  • Nevada has no state electrician license; Las Vegas, Clark County and Reno require an Electrical Qualifications ID card on every job site.
  • Electrical Safety Professionals (ESP) issues the cards, after you pass an ICC national exam: G17 journeyman, G16 master, G18 residential or G21 low voltage.
  • ICC electrician exams are open book with the NEC, and ICC offers them in more than one code edition, so match the edition to the exam you book.
  • Cards are valid for 3 years; one expired for more than a year means taking the exam again.
